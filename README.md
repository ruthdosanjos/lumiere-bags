## 📖 Sobre o projeto

**LUMIÈRE** é um e-commerce fictício de bolsas desenvolvido como projeto de portfólio para demonstrar conhecimentos em desenvolvimento Front-end.

O projeto simula a experiência de uma marca premium, combinando uma identidade visual minimalista com uma arquitetura de código organizada, modular e preparada para crescimento.

Além do design, o foco principal está na construção de uma aplicação escalável utilizando apenas tecnologias nativas da web, explorando boas práticas de arquitetura, organização de código, acessibilidade, performance e reutilização de componentes.
